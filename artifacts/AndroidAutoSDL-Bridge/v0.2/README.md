# Versão 0.2 — registro histórico

A documentação do desenvolvimento registra a 0.2 como correção do conflito da permissão de assinatura com o Open Headunit original (versionCode 122). Essa versão ainda precede a correção do fechamento em telas de retrato, entregue na 0.3.

O APK e um pacote-fonte isolado da 0.2 não estavam entre os artefatos disponíveis ao montar este repositório. A versão fica registrada aqui para explicar a sequência; use a 0.3 para novos ensaios.
